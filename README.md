# SAGE Craft

Воксельная песочница на [SAGE Engine](https://github.com/AmckinatorStudios/SAGE-Engine) —
стресс-тест движка на настоящей игре. Это **отдельный проект редактора**:
сцена, скрипты, шейдеры и материалы открываются и правятся в SAGE Editor,
движок про игру ничего не знает.

## Что есть

- Бесконечный по горизонтали мир из участков 16×16×128: холмы, горы,
  пустыни, снег, леса, пещеры, руды, вода. Мир — по зерну (`--seed=`).
- Освещение по вокселям, без динамических теней: свет неба и свет блоков
  (факел, светокамень) по 16 уровням, сглаженный свет и затенение углов.
- Небо Minecraft 1.7.10: сутки 24000 тиков (20 минут), угол небесной сферы
  по calculateCelestialAngle, солнце и луна с 8 фазами (`sun.png`,
  `moon_phases.png`) на сфере радиуса 100, 1500 звёзд по `Random(10842)`,
  цвет неба по температуре биома (равнина — #78A7FF), заря-веер на восходе и
  закате, туман цвета неба у горизонта с оттенком зари со стороны солнца.
- Погода по World.updateWeather: дождь и гроза со своими сроками, плавная
  сила, серое небо в дождь, тёмное в грозу, холодная вспышка молнии.
- Облака 1.7.10: `clouds.png`, клетка 12 блоков, высота 128, толщина 4,
  ветер на запад; цвет — по времени суток и погоде.
- Рука от первого лица — отдельным проходом камеры: в блоки не уходит.
- Игрок: ходьба, бег, присед (не падает с края), прыжок, плавание, полёт (F).
  Скорости как в Minecraft: шаг 4.317, бег 5.612 блока/с. Бег включается
  нажатием Ctrl при движении вперёд и сбивается остановкой, приседом, стеной
  или водой.
- Песок и гравий без опоры падают телом — плавно, с разгоном, как в
  Minecraft (20 тиков/с, −0.04 и ×0.98 за тик), и ложатся блоком.
- Добыча с трещинами и временем по прочности блока и инструменту, выпадение
  предметов, подбор, крошки.
- Рюкзак на 36 ячеек, панель 1–9 и снаряжение, стопки до 64,
  перетаскивание, деление стопки. Крафт руками: сетка 2×2 в рюкзаке, 3×3 у
  верстака (ПКМ по нему). Печь (ПКМ по ней): сверху что плавить, снизу
  топливо (уголь — 80 с, дерево — 15 с), предмет плавится 10 с; огонь и
  стрелка в окне показывают топливо и ход плавки, горящая печь светится.
  Работают все загруженные печи, содержимое сохраняется.
- Меню одиночной игры как в Minecraft Java 1.7.10 (`scripts/menu.lua`,
  `gui.lua`, `worlds.lua`, `panorama.lua`) — на интерфейсе движка:
  титульный экран с вращающейся размытой панорамой (числа `GuiMainMenu`),
  логотип SAGE Craft, жёлтая «дышащая» надпись, Singleplayer / Options... /
  Quit Game; Select World — список миров с превью, названием, папкой и
  датой, режимом, прокрутка, двойной щелчок; Create New World (название,
  папка «Will be saved in», режим — только выживание); Rename, Delete с
  подтверждением; Options (поле зрения, дальность, громкость, музыка,
  чувствительность — сохраняются); Esc в игре — Game menu (Back to Game /
  Options... / Save and Quit to Title); экраны «Loading world» и «Saving
  world»; переходы — растворением. Мир строится только после Create New
  World или Play Selected World; каждый мир — свой слот сохранения (рюкзак,
  постройки, место, печи, карты, время). Превью — кадр мира без интерфейса
  при выходе в меню. Сохранение прежних версий видно как мир «World».
- Музыка главного меню — как в Minecraft 1.7: случайный трек (`assets/music/
  menu1–4.ogg`), между треками пауза 1–30 с, при входе в игру музыка уходит.
- Иконка игры (`assets/icon.png`) и сведения о файле (версия, автор,
  описание) — раздел `"game"` в `project.sageproj` (в редакторе — окно Game
  Settings); сборка вшивает их в `SAGE Craft.exe`.
- Весь текст в игре — на английском (названия блоков и предметов как в
  английском Minecraft).
- Здоровье (восстанавливается само) и опыт за руду. Голод пока выключен —
  есть почти нечего (`Hud.HUNGER` в `scripts/hud.lua`).
- Руды — по правилам Minecraft Java 1.7.10 (`scripts/ores.lua`: копия
  `java.util.Random`, `WorldGenMinable`, `BiomeDecorator`): на каждую руду —
  число попыток на участок, X/Z случайно в участке, Y по правилу руды; жила —
  вытянутая полоса шариков переменного радиуса со случайным направлением и
  сдвигом по высоте, заменяет только камень. Уголь 20 попыток × до 16 блоков,
  Y 0–127; железо 20 × 8, Y 0–63; золото 2 × 8, Y 0–31; красная пыль 8 × 7,
  Y 0–15; алмазы 1 × 7, Y 0–15; лазурит 1 × 6, Y = nextInt(16) + nextInt(16)
  (0–30, чаще около 15); изумруд — только в Extreme Hills и Edge, 3–8
  одиночных блоков на участок, Y 4–31. Так же — жилы земли и гравия. Выпадение
  и опыт как в оригинале (красная пыль 4–5, лазурит 4–8). Факел светит
  уровнем 14.
- Анимации игрока как в 1.7.10 (`scripts/anim.lua` — состояние по тикам,
  `avatar.lua` — ModelBiped, `hand.lua` — ItemRenderer): ходьба и бег
  (раскачка по скорости), покой, голова за взглядом, тело доворачивается за
  движением, присед (тело 0.5 рад, руки, ноги, голова; без уменьшения
  коробки), взмах при ударе и постройке, предмет в руке, прицел из лука двумя
  руками, защита мечом. От первого лица: рука или предмет, появление и уборка
  при смене ячейки, взмах, еда и питьё у рта, натяжение лука, защита, карта
  двумя руками; покачивание камеры и руки при ходьбе, плавный присед камеры.
- Предметы для этих действий: лук и стрелы (стрелы летят и застревают,
  подбираются), бутылка (набрать воду ПКМ по воде, выпить), бумага из
  тростника (растёт у воды), компас, карта (пустая карта по ПКМ — карта
  местности 128×128). Нить для лука в мире пока не добыть.
- Снимок экрана — F2: файл `ГГГГ-ММ-ДД_ЧЧ.ММ.СС.png` в папке `screenshots/`
  каталога игры (рядом с сохранениями), в чате — «Saved screenshot as …».
- Рука и предмет в руке от первого лица, превью персонажа в рюкзаке.
- Объёмные иконки блоков, собранные из текстур при старте.
- Модель игрока со скелетом: ходьба, бег, присед, взмах, голова за взглядом.
  Вид от первого лица, сзади и спереди (F5).
- Свои скины (см. ниже). Сохранение мира, рюкзака и скина.

## Запуск

Из редактора: **Open Project** → папка с этим `README.md` → сцена
`scenes/main.sage` → **Play**. Или собранным плеером движка:

```bash
./build/runtime/SagePlayer /путь/к/Minecraft-SAGE-Edition
```

Готовая игра для Windows — в релизе `latest`: распакуйте архив и запустите
`SAGE Craft.exe`. Это собранная игра (`game.sagepak`), а не проект; исходники —
сам репозиторий. Собирает её `sage_build` движка — та же упаковка, что
**File → Build Game** в редакторе:

```bash
sage_build --project /путь/к/Minecraft-SAGE-Edition --player SagePlayer --out build
```

Игре нужен движок не старше коммита из `engine-min.txt`. Выпуск ждёт, пока
релиз движка `windows-latest` догонит `main` движка, и не соберётся со
старым плеером. Плеер старше игры при запуске пишет в лог одну понятную
ошибку («SAGE Craft failed to start…»), а не поток следствий.

Параметры: `--seed=42`, `--view=6` (дальность в участках), `--fresh=1`
(новый мир), `--time=6000` (тики: 0 — восход, 6000 — полдень, 12000 — закат, 18000 — полночь; до 1 — доля суток), `--weather=clear|rain|thunder`, `--lightning=1` (держать вспышку молнии), `--skin=путь.png`,
`--autopilot=1 --quit=1` (прогон без рук, итог — строка `AUTOPILOT` в логе),
`--gencheck=1` (проверка генерации: высота столба по точке и по сетке, мир при
отрицательных координатах, деревья через границу участка, расстояние между
стволами, доля угля и железа; итог — строка `GENCHECK`; плюс `LIGHTCHECK` —
свет факела 14, 13, … по клеткам, и `UICHECK` — клетки окон на клетках
картинки). Для снимков: `--torches=1`, `--openinv=1`, `--craftdemo=1`,
`--crack=N`, `--dropdemo=1`, `--furnacedemo=1`, `--kit=1`, `--slot=N`, `--yaw=`,
`--pitch=`; `--nomenu=1` — сразу в игру, без главного меню. Для снимков
анимаций: `--animkit=1` (меч, лук, стрелы, еда, вода, карта), `--hold=имя`,
`--forceuse=1` (держать ПКМ), `--forceswing=1`, `--sneak=1`, `--walk=1`,
`--menu=select|create|options|rename|delete` (`--pick=1` — выбрать
первый мир) — сразу экран меню; `--menutest=1` — сквозная проверка меню
(строка `MENUCHECK`: мир не строится до создания, после выхода в меню и
перезапуска он в списке с превью и датой, блок, рюкзак и место на месте);
`--third=1|2`, `--orbit=градусы` (камера вокруг игрока), `--shotat=секунды
--shotname=имя` (снимок через F2-механику). `ANIMCHECK` в `--gencheck` —
числа анимаций (взмах, шаг, смена предмета, еда, присед, матрицы). `FURNACECHECK` в
`--gencheck` — переплавка, огонь и погасание печи; `FALLCHECK` — падение
песка телом. Автопилот проверяет и бег: одно нажатие — 5.612 блока/с.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | идти |
| Пробел | прыжок / всплыть / вверх в полёте |
| Shift | присесть / вниз в полёте |
| Ctrl | бег: нажать (не держать) — держится, пока идёте вперёд |
| ЛКМ (держать) | ломать |
| ПКМ | поставить; с едой, бутылкой, луком, мечом — использовать (держать) |
| СКМ | взять такой же блок |
| 1–9, колесо | ячейка панели |
| E | рюкзак (крафт 2×2) |
| ПКМ по печи | окно печи |
| Esc | меню игры (Game menu) / закрыть окно |
| Enter | подтвердить в меню (создать мир, переименовать) |
| ПКМ по верстаку | крафт 3×3 |
| Q | выбросить один |
| F | полёт |
| F2 | снимок экрана |
| F3 | отладка (и биом) |
| F5 | вид |
| K | следующий скин |

## Свои скины

Положите PNG 64×64 (развёртка модели `assets/models/player.gltf`) в
`assets/skins/` под именем `custom.png` или `skin1.png` … `skin9.png`
и нажмите K в игре. Или запустите с `--skin=путь/к/скину.png`.

## Устройство

| Файл | Что делает |
|---|---|
| `scripts/game.lua` | точка входа, порядок кадра, управление |
| `scripts/world.lua` | хранилище клеток (секции 16³, свет в том же числе) |
| `scripts/gen.lua` | генерация по зерну |
| `scripts/light.lua` | свет волной: заливка и снятие при правке |
| `scripts/mesher.lua` | меш секции, сглаженный свет, затенение углов |
| `scripts/chunks.lua` | загрузка/выгрузка участков в бюджете кадра |
| `scripts/atlas.lua` | атлас граней и лист иконок из картинок |
| `scripts/player.lua` | тело игрока, столкновения, луч по клеткам |
| `scripts/interact.lua` | добыча и постройка |
| `scripts/inventory.lua` | рюкзак, стопки, экран крафта |
| `scripts/crafting.lua` | рецепты сеткой |
| `scripts/hand.lua` | рука и предмет от первого лица (ItemRenderer 1.7.10) |
| `scripts/anim.lua` | состояние анимаций по тикам (взмах, шаг, тело, камера, предмет) |
| `scripts/mat.lua` | матрицы glTranslate/glRotate → положение и углы движка |
| `scripts/ores.lua` | руды 1.7.10 (java.util.Random, WorldGenMinable) |
| `scripts/map.lua` | карта: цвета местности, карта в руке |
| `scripts/arrows.lua` | стрелы (EntityArrow) |
| `scripts/drops.lua` | выпавшие предметы |
| `scripts/avatar.lua` | модель игрока, движения, скины |
| `scripts/sky.lua`, `scripts/clouds.lua` | небо 1.7.10: время, светила, звёзды, заря, туман, облака |
| `scripts/weather.lua` | дождь, гроза, молнии |
| `shaders/chunk.*` | свет по вокселям, стороны граней, туман |
